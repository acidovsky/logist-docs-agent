# Logist Docs Agent

Многопользовательский веб-сервис для работы с пакетами логистических документов.

## Структура проекта

- `backend/` — серверная часть на FastAPI, SQLModel и SQLite. Код приложения находится в `backend/app/`, загруженные файлы — в `backend/uploads/`.
- `frontend/` — интерфейс на React и TypeScript, собирается через Vite.
- `legacy/` — исходный прототип на Streamlit. Папка сохранена для справки и не изменяется.

## Запуск

Backend:

```powershell
cd backend
.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8000
```

Frontend:

```powershell
cd frontend
npm run dev
```

Интерфейс открывается по адресу `http://localhost:5173`, документация API — `http://localhost:8000/docs`. Запросы с интерфейса на `/api` проксируются на backend.

## Проверка полного цикла

1. Откройте `http://localhost:5173/register` и зарегистрируйте пользователя — после регистрации сразу выполнится вход и откроется список сделок.
2. Нажмите «Создать сделку», заполните название и описание.
3. Откройте созданную сделку по её названию.
4. Перетащите скан JPG, PNG или PDF в область загрузки либо выберите файл нажатием.
5. Дождитесь появления документа в списке: рядом с типом отобразится уверенность классификатора.
6. Проверьте чек-лист: найденные документы отмечены галочкой, отсутствующие — крестиком.
7. Зарегистрируйте второго пользователя в другом браузере и убедитесь, что он не видит первую сделку.

Для проверки распознавания подойдёт изображение с текстом «ТОВАРНО-ТРАНСПОРТНАЯ НАКЛАДНАЯ» — классификатор определит его как ТТН.
