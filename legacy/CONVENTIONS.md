# Правила для AI-агента (Aider)

1. Одна задача — один шаг.
2. Сначала план — потом код.
3. Если не уверен — спроси.
4. Не добавляй зависимости без разрешения.
5. Комментарии на русском, имена — на английском.

## Код
- Python 3.11+, PEP 8.
- Type hints обязательны.
- Одна функция — одна ответственность.
- Логирование через logging, не print.

## Структура
- app.py — Streamlit.
- src/ocr.py — распознавание.
- src/classifier.py — классификация через LLM.
- src/checker.py — сверка с конфигом.
- src/config_loader.py — загрузка config.yaml.
- config.yaml — обязательные документы.
- output/ — сохранённые пакеты.

## Git
- Коммит после каждой рабочей фичи.
- Сообщение на русском, кратко.
- Не коммить сломанный код.

## Безопасность
- Не удалять файлы за пределами проекта.
- Не ставить глобальные пакеты.
- Ключи — только через env, не хардкодить.
